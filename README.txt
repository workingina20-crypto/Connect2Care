# Connect2Care installable web app prototype

This package is a Progressive Web App (PWA) prototype for Android and desktop browsers.

## Install on Android
1. Upload the contents of this folder to a static web host that provides HTTPS (for example, a school-approved web host or GitHub Pages).
2. Open the hosted site in Chrome on Android.
3. Tap the browser menu (⋮), then choose **Install app** or **Add to Home screen**.
4. Confirm. Connect2Care will appear on your home screen.

## Important limitations
- This is a demonstration prototype, not a production social-work or emergency reporting system.
- The sample report form does not transmit or store information.
- Do not enter real names, addresses, abuse disclosures, medical details, or other sensitive personal information.
- Emergency help in the Philippines: call 911 if someone is in immediate danger.
- Before real deployment, the app needs a secure backend, authorized staff workflow, privacy notice, consent process, encryption, access controls, data retention rules, and verified local referral contacts.
- A PWA package is not an APK. It installs from a secure website through the browser. Building a signed APK requires an Android build environment and app signing.
